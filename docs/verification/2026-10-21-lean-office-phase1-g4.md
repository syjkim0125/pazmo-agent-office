## 질문과 답 (2026-10-27)

컨트롤러가 G4 설명 페이지("Office 다시 짜기", 1단계 G4 판)와 대화로 세 질문, 선택지(① 승인 후 머지, ② 후속을 먼저 고치고 G4, ③ 머지하지 않음), 답 초안을 냈다. 사용자가 앞서 Office 안의 작업 G4에서 "답 초안 너가 써줘 보고 고칠게"라고 했던 방식이다. 사용자는 초안을 고치지 않고 이렇게 답했다.

> 피드백 확인 후 승인

사용자가 승인한 답(초안 그대로):

1. `./office --lean`으로 켜면 Claw 없이 Tasks·작업 상세·Decisions·Agents 화면만 있는 Office가 뜬다. agent마다 작업 실행기와 리뷰 실행기를 따로 고를 수 있어 다른 모델이 리뷰하게 할 수 있다. `--lean`을 붙이지 않으면 지금과 같다. 덤으로 claude 리뷰어가 설명 뒤에 붙인 JSON 보고서도 읽혀서, 그 때문에 작업이 멈추던 일이 없어진다(Claw에도 해당).
2. 규칙: `127.0.0.1`에서만 열리고 세션·CSRF를 검사한다. `--lean`이 없으면 Claw 엔진은 그대로다. 일하는 중이거나 마지막인 agent는 못 지우고, 진행 중인 작업이 있으면 Office를 못 멈춘다. 실패 시: 엔진이 멈추면 "멈춤"과 이유가 보이고 자동 재실행은 없다(취소만). 리뷰 보고서를 못 읽으면 unknown으로 멈춘다. 리뷰 실행기가 오류로 끝나면 fail로 기록되고 구현부터 다시 돈다.
3. 확인: 시험 927/927, 타입 검사 0, eevee-be에서 다른 실행기(sonnet) 리뷰로 G1→구현→리뷰→G4→인도, agent 추가·변경·삭제와 거부, Decisions 링크. 못 한 것: codex 리뷰 실행기, 설명+블록 보고서의 실제 실행, 다른 사람 PC·여러 날 운영.
