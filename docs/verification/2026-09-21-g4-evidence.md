# G4 evidence and understanding protocol — 2026-09-21

Story M2/M4/M5, V2/V4/V5. [Task](../tasks/U7-g4-evidence.md). This connects persisted verified evidence to G4 question/answer APIs. The application's G4 protocol is implemented in part; this repository's human G4 gate has not passed.

## Implemented boundary

Historical protocol checkpoint below. The follow-up [mechanical candidate diff](2026-09-21-candidate-diff.md) replaces the raw-string seam; current `prepare` is async and accepts a frozen baseline. Old unverified bundles are retained but ineligible.

`CompletionLedger.prepare` accepts a trusted controller's raw diff only after the same candidate has all required results and released execution receipts for every test/review node, with no unresolved execution for that task. Directly inserted verification observations without execution receipts cannot open G4. The bundle binds the verification subject and raw-diff digest and cannot be replaced for that round.

The operator requests G4 through the existing approval API/CLI. The response contains the raw diff, contract references/digests, captured test/review results and three understanding questions. No generated solution explanation or prefilled assessment is provided. Submitting the human's own behavior, invariant/failure-path and evidence-boundary answer records `awaiting_evaluation`; it grants no approval. Additional `evaluation`/`approved` fields in the answer are ignored. Human rejection is recorded without acceptance.

The separate controller-internal evaluator must compare that exact answer digest with the bundle, record a rationale for all three dimensions, and mark each correct before `ApprovalLedger` can record acceptance. An incorrect dimension produces `needs_restatement`; a new challenge and new answer are required, while the previous answer/evaluation remain stored. There is no HTTP/CLI endpoint for preparing a diff or submitting an evaluation.

Accepted G4 remains scoped to the current candidate/contract/evidence. It does not set the task to done, apply files, merge, deliver or unlock execution. Inspection revalidates evidence; changed candidates/contracts and cancelled rounds report stale. Expired or prior-operator-session pending questions report expired. Accepted historical approval survives restart only while the evidence remains current.
