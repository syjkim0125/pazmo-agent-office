요청과 대화를 저장하고, 필요한 결정에 답하는 공간입니다.

실행 상태를 확인하세요. 실제 모델 사용에는 검증된 live 실행 설정이 필요합니다.

이 Office에 연결

Office를 시작한 터미널에서 확인한 operator 인증키를 입력하세요. 연결 해제나 새로고침 시 다시 입력해야 합니다.

인증키는 현재 페이지의 메모리에만 보관합니다. 공유 화면에서 키를 표시하지 마세요.

실행 결과

등록된 작업의 변경 내용과 검증 결과를 확인하고 G4 답변을 제출합니다. 실행 계획을 승인한 뒤 모델 작업을 시작할 수 있습니다. 최종 승인이 확인된 결과물은 여기서 인도받습니다.
